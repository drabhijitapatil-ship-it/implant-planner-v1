Implanr treats every case record like it belongs to a real person — because it does. HIPAA-aware technical safeguards, immutable audit trails, and defence-in-depth engineering, from the login screen down to the database.

Technical Safeguards

Defence-in-depth, phase by phase.

15-min Auto-Logout
Every inactivity timer respects HIPAA's minimum-necessary-access principle — closed session, closed record.
Screen-Capture Block
Native iOS & Android APIs render screenshots blank — accidental leaks, prevented at the OS level.
Immutable Audit Log
Every view, every export, every override — logged with user, IP, and timestamp. CSV export in one click.
Role-Based Access
Five roles, five scopes. Students see their cases; supervisors see their cohort; admins see the audit trail.
TLS 1.3 In Transit
Every byte between device and server is encrypted with modern ciphers. HSTS enforced on every route.
Encrypted At Rest
Database volumes are AES-256 encrypted. PHI fields carry an additional application-layer envelope.
Data Architecture

Tenant-isolated. Region-aware. Backup-tested.

Institutions are multi-tenant-isolated by default — no case, log, or PDF crosses tenant boundaries. Data residency options include India (Mumbai), EU (Frankfurt), and US-East for institutions with specific regulatory needs.
